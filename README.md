# 📊 HR Analytics – Exploratory Data Analysis

An Exploratory Data Analysis (EDA) project using **Python** to analyze employee data and identify patterns related to employee attrition, workforce characteristics, job roles, salary, and other HR factors.

---

## 🚀 Project Overview

This project focuses on analyzing an HR dataset using Python to understand employee characteristics and identify patterns that may be useful for HR and business analysis.

The analysis includes data cleaning, exploratory analysis, statistical analysis, visualization, and business insight generation.

---

## 🎯 Business Objectives

The analysis focuses on questions such as:

* What is the overall employee attrition rate?
* Which departments have higher employee attrition?
* Which job roles have higher attrition?
* How does attrition vary across different age groups?
* How does attrition vary by gender?
* Is there a relationship between salary and employee attrition?
* How does employee experience relate to attrition?
* What workforce patterns can be identified from the dataset?
